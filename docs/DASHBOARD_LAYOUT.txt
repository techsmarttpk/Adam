2. COMPONENT SPECIFICATION: LEFT SIDEBAR CONTROL RAIL
--------------------------------------------------------------------------------

2.1 Brand Header
    - Title: "🛡️ ADAM"
    - Subtitle: "Adaptive Deception Sandbox"
    - Purpose: Visual anchor and product identity.

2.2 Pre-Flight Sandbox Health Indicator
    - Status Badge: "🟢 Ready" (when VM is clean/off) or "🔴 Not Ready"
    - Sub-metrics: VM State ("Off" / "Running") | Guest Agent ("Reachable" / "Offline")
    - Snapshot: Exact active VirtualBox snapshot name (e.g. `disk-resized-36gb-c-drive`)

2.3 Target Malware Sample Selector
    - Radio Options:
      1. "Pre-loaded Benchmark" -> Defaults to `samples/smoke_sample.exe`
      2. "Upload Custom" -> Activates drag-and-drop file uploader for any custom `.exe` binary.

2.4 Sandbox & Deception Configuration
    - Profile Dropdown: `bare_control`, `enterprise_office_decoy`, `developer_decoy`
    - Deception Toggle: `[x] Enable Deception`
      * Checked   -> Treatment Arm (Active Real-Time Decoy Injection)
      * Unchecked -> Control Arm (Passive Baseline Observation / Monitor Only)

2.5 Execution Action Buttons
    - Primary Action: `[⚡ Run Live VM Detonation]` (Full end-to-end VM boot, detonation, telemetry capture, teardown)
    - Action 2: `[🚀 Replay Demo]` (Instant offline synthetic behavioral replay via Fusion Engine)
    - Action 3: `[🔄 Reset VM]` (Forced poweroff and clean snapshot restoration)

2.6 Session Explorer (Historical Triage Dropdown)
    - Lists all live, replay, and simulation sessions ordered by newest first.
    - Dynamic Status Indicators:
      * 🟢 `[LIVE] sess_<id> (COMPLETED)`
      * 🟡 `[LIVE] sess_<id> (RUNNING)`
      * 🔴 `[LIVE] sess_<id> (FAILED)`
      * 🚀 `[REPLAY] replay_<id> (COMPLETED)`

3. COMPONENT SPECIFICATION: MAIN THREAT INTELLIGENCE CANVAS
--------------------------------------------------------------------------------

3.1 Session Executive Header & Badges
    - Session ID Title: `📊 SESSION: <session_id>`
    - Subtitle: `Experiment: <exp_id> • Started: <Local Datetime with Timezone>`
    - Pill Badges (Top Right):
      * `[NET: HOST_ONLY]` -> Air-gapped network isolation badge
      * `[ARM: TREATMENT]` (Blue) / `[ARM: CONTROL]` (Slate) -> Deception state
      * `[COMPLETED]` (Emerald) -> Session completion status

3.2 Numeric KPI Metric Cards & Quick Export Bar
    - Stat Tile 1: `Events` (Count of fused high-signal semantic events, e.g. 98)
    - Stat Tile 2: `Mutations` (Count of active deception lures injected, e.g. 5)
    - Stat Tile 3: `Decisions` (Count of policy rule evaluations, e.g. 98)
    - Stat Tile 4: `ATT&CK Techs` (Count of unique MITRE techniques mapped, e.g. 6)
    - 1-Click Action Buttons:
      * `[📥 HTML]` -> Downloads standalone self-contained forensic report
      * `[📥 MD]`   -> Downloads Markdown documentation
      * `[📥 JSON]` -> Downloads structured JSON data payload

3.3 Compact Forensic Metadata Summary Strip
    - High-density dark card `#161b26` with border accent `#283143`:
      * `Target Sample:` Filename of analyzed binary
      * `VM Profile:` Guest OS personality profile
      * `Deception Engine:` `ACTIVE (TREATMENT)` vs `MONITOR ONLY (CONTROL)`
      * `SHA-256 Hash:` Complete 64-character cryptographic hash with `user-select: all` for 1-click copy into VirusTotal/OTX.

3.4 MITRE ATT&CK® Coverage Section
    - Inline Tactic Color Legend:
      * ● Discovery (Sky Cyan)
      * ● Credential Access (Crimson Red)
      * ● Persistence (Electric Indigo)
      * ● Command & Control (Hot Pink)
      * ● Defense Evasion (Warm Amber)
      * ● Collection (Teal)
    - Dynamic Coverage Pills:
      * Each mapped technique is color-coded by its parent tactic (e.g. `Discovery (TA0007) / T1083`).

3.5 Indicators of Compromise (IOCs) & Planted Artifacts Table
    - Unified forensic table with color-coded left-border visual distinction:
      * Emerald Left-Border (`EVENT`): Real observed attacker file reads, registry scans, directory searches.
      * Amber Left-Border (`MUTATION`): Active deceptive lures injected (fake passwords, browser logins, decoy run keys, fake C2 responder).
    - Columns: `Source` | `Target / Path` | `Operation`

3.6 Behavioral Timeline (Chronological Stream)
    - Timezone: Formatted strictly in local system time down to milliseconds (`HH:MM:SS.mmm`).
    - Sliding Window Deduplication: Automatically filters consecutive identical sliding-window events.
    - Confidence Badges:
      * `92% CONF` (Emerald): High confidence detection
      * `75% CONF` (Yellow): Moderate confidence
      * `APPLIED` / `PLAUS: 1.00` (Blue): Deception lure applied with plausibility score.

3.7 Raw OS Telemetry Artifacts Section
    - Explicit Raw Volume Metric: `📁 6,446 total raw OS telemetry events recorded...` (Demonstrating 65:1 signal-to-noise compression).
    - Direct Downloads:
      * `[📥 Download Full raw.jsonl (6.37 MB • 6,446 events)]`
      * `[📥 Download Full sysmon.evtx (8.07 MB)]`
    - Artifact Path: Local disk filesystem path for direct terminal/forensic access.
