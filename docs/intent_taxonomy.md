# ADAM Semantic Intent Taxonomy Matrix

This document defines the complete semantic intent taxonomy, ATT&CK mapping, severity classification, confidence gating, policy behavior, and deception primitives in ADAM.

## Severity Tiers

- **CRITICAL (90–100)**: Immediate destructive progression, active C2 control, ransomware encryption, high-confidence evasion, or critical credential harvesting. Confidence Gate: `≥ 0.85–0.90`.
- **HIGH (70–89)**: Significant attack progression across persistence, lateral movement, injection, and evasion. Confidence Gate: `≥ 0.80`.
- **MEDIUM (40–69)**: Contextual behaviors, scripts, or reconnaissance. Default to OBSERVE or require corroborating context. Confidence Gate: `≥ 0.70`.
- **LOW (10–39)**: Background OS telemetry, basic info querying. OBSERVE only. Confidence Gate: `≥ 0.60`.
